# Anymd Governance & Decentralized User Meow

This project is built on the core principle of **Decentralized User Meow (KawaiiNekoty)**. 
All data, files, companion sidecars, and keys belong exclusively to the user and remain local-first.

3. **Decentralized Ingestion**: The user has full control over what books, documents, and feeds are imported into their private vaults.

## Upstream Technical Hygiene

To ensure the safety and clean state of the community repository, automated tests and pre-push filters are run to scrub credentials and PII. No user data is sent upstream.
Any reported DMCA or compliance violations can be programmatically removed using the provided `compliance_remove.py` toolkit.
