## [20260826-1804] AnyMD Unified Chromatic Hierarchy (Tabs & Vault Pills)

# Tags: #zettelkasten #anymd #ui_design #design_system #color_theory

• Core Summary:

* Establish chromatic inheritance where **Vault Pills dynamically adopt the accent color of their parent Mode Tab**.
* Creates instant peripheral spatial orientation: seeing an amber or sage vault pill immediately anchors it to the matching Blueprint or Journal folder drawer.
* Eliminates visual noise by replacing arbitrary pill borders with a strict, functional color-coding system across workspaces.

• Peripheral Nodes / Context:

* UI Pattern: Parent-Child Color Inheritance & Visual Grouping
* Complements: Manila hanging folder tab metaphor and per-vault theme isolation.

• Raw Transcribed Text / Snippets:

> Design rule: Mode Tab color $\rightarrow$ Inherited by Vault Pills $\rightarrow$ Tinted Workspace Shell.

---

**Chromatic Inheritance Mapping**

| Mode Folder Tab | Tab Accent Tone | Inherited Vault Pill Styling | Example Vaults |
| --- | --- | --- | --- |
| **Books** | Slate Indigo / Heather Blue | Soft indigo fill, high-contrast dark text, indigo halo on focus | `📖 StoryCraft Lore`, `📚 Calibre Local` |
| **Journal Vaults** | Warm Sage / Mint Slate | Sage pill border, subtle sage glow, muted tag text | `📓 Daily Log`, `🧠 Telemetry Reflection` |
| **Blueprints** | Manila Amber / Ochre Gold | Ochre manila tab background, crisp amber pill chip | `📐 App Specs`, `⚙️ System Blueprints` |
| **Sandboxes** | Vivid Iris / Amethyst Purple | Deep purple outline, glowing violet indicator dot | `🧪 AGV Experiments`, `🎲 Fast Prototyping` |

---

**Visual Benefits**

* **Zero-Lookup Context Awareness**: You don't have to read the text labels to know if a vault belongs to creative fiction, system planning, or personal logs—the color coding handles recognition instantly in your peripheral vision.
* **Cohesive Folder-to-Drawer Feel**: When you switch to the **Blueprints** tab, all available vault pills shift or highlight in matching manila-amber tones, reinforcing the mental model of pulling a folder out of that specific drawer.
* **Distinct Work-Mode Guardrails**: Corporate or work-designated vaults can inherit a dedicated high-visibility warning tint (e.g., steel blue or alert orange) that overtakes the pill strip and top frame to prevent mixing work logs with personal sandboxes.
