# 📟 @lorik/meow-mud

> **The Meow MUD Retro ANSI Studio & MIDI Soundtracker Sequencer**

A decoupled, lightweight package designed to separate your ASCII/ANSI movie streams [cite: 420] and game cartridge compiles [cite: 415, 421] into a standalone, nostalgic workspace! This tool introduces an interactive 80x25 terminal layout editor featuring complex character layering and procedural MIDI music generation [cite: 365, 415].

---

## 🎨 Creative Philosophy: 90s MUD Culture
We return digital creation back to its root terminal structures! By wrapping stacked, transparent layer planes and assigning ASCII density values to FM-Synth frequency tables, you can design playable visual novels, terminal movies, and base64 chiptunes completely offline [cite: 365, 413, 419, 420]!

---

## 🎹 Keyboard Shortcuts & Controls
- `Escape`: Instantly dismisses active FAQ/Changelog modal panels [cite: 615].
- Click Canvas Cell: Triggers a dialog prompt to paint, edit, or color-code individual coordinate glyphs.
- **Export MIDI:** Generates and initiates a direct browser download of standard 90s <code>.mid</code> SMF sequence files [cite: 415].
