Welcome to the absolute native, zero-WebView, high-performance Android compilation system for the anyMD local-first ecosystem. 

This codebase permanently scraps the legacy WebView/HTML stubs and establishes raw, native, low-latency Kotlin components running directly over the Android 14 NPU and standard Bluetooth HID profile frameworks.

## 🚀 Execution & Hotkeys
* **D-Pad Navigation:** Fluid 4-way direction pad routing Standard USB HID scancodes:
  * `UpArrow`: `0x52`
  * `DownArrow`: `0x51`
  * `LeftArrow`: `0x50`
  * `RightArrow`: `0x4F`
* **Trigger Shortcut:** Tap `Double-Tap Power Button` to execute the Hardware Emergency Panic Abort, immediately resetting all active Bluetooth macros, releasing all HID channels (reports to `0x00`), and purging staging queues.
* **Mute/Suppress Pattern:** Tap `[ ✕ ]` inside any focus frame to immediately log to `.buddysuppress.json` and mute notifications.
* **Keep-Alive Toggle:** Trigger Shizuku binding over ADB/privileged shell to whitelist AnyMD and local n8n against OxygenOS/Doze battery optimization cycles.
